# Armagedon — Reglas del sistema

> Estado: Pre-alpha  
> Estas reglas están en desarrollo y pueden cambiar durante las pruebas.

## 1. Sistema base

Armagedon utiliza un sistema basado en d20.

La resolución básica de una prueba es:

`1d20 + modificador de característica + bonificador de competencia (PB, cuando corresponda)`

## 2. Características

El sistema utiliza seis características principales:

- Fuerza (STR)
- Destreza (DEX)
- Constitución (CON)
- Inteligencia (INT)
- Sabiduría (WIS)
- Carisma (CHA)

### Fuerza

Además de sus usos habituales, Fuerza representa la capacidad del personaje para controlar físicamente armas pesadas, retroceso y disparos desde posiciones poco estables.

### Destreza

Además de sus usos habituales, Destreza representa la precisión del personaje con armas a distancia.

## 3. Proficiency Bonus

Armagedon conserva el Proficiency Bonus (PB).

El PB representa entrenamiento y dominio, y puede utilizarse como valor de escalamiento para armas, modificaciones y otras características.

## 4. Economía de acciones

Durante su turno un personaje dispone de:

- Movimiento
- Action
- Bonus Action
- Reaction

## 5. Armas

### Daño

Las armas poseen su propio perfil de daño.

El daño de un arma no añade automáticamente STR o DEX.

### Munición

Las armas que utilizan munición poseen una capacidad de cargador determinada.

Ejemplo:

`Lasgun — 12 disparos`

## 7. Compatibilidad de equipo

El equipo puede estar diseñado para determinadas especies, fisiologías o usuarios.

Utilizar equipo incompatible puede imponer requisitos o riesgos adicionales.

Ejemplos:

- Fuerza mínima para armas Astartes.
- Riesgo radiológico para determinadas armas Rak'Gol.
- Problemas de fiabilidad al utilizar tecnología Ork sin familiaridad.
- Riesgos biológicos al utilizar bioarmas Tyranid.

La incompatibilidad no implica que un arma sea inherentemente defectuosa para su usuario previsto.

## 8. Modificaciones

Las armas podrán aceptar modificaciones que alteren su funcionamiento.

Una modificación puede proporcionar beneficios a cambio de costes como:

- Mayor peso.
- Menor capacidad.
- Mayor consumo de munición.
- Penalizaciones al sigilo.
- Mayor retroceso.
- Riesgos adicionales.
